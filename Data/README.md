# House Price Prediction - Machine Learning Project

This is a beginner-level Machine Learning project that predicts housing prices based on features such as area, number of bedrooms, and location using Linear Regression.

## 📌 Project Overview
- **Language:** Python
- **Libraries Used:** Pandas, NumPy, Scikit-Learn, Matplotlib
- **Algorithm:** Linear Regression
